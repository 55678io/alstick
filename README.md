# alstick

White web app: "Alstick" text logo splash → 6‑digit PIN login → 3 sec loading → home page, with OneSignal web push.

## OneSignal setup
1. onesignal.com par **Web** app banayein, Site URL: `https://55678io.github.io`
2. App ID `onesignal.js` me set hai (OneSignal app: Alstick).
3. Dashboard > Messages se push bhejein.

Note: PIN client-side code me hai, isliye ye asli security nahi hai.
